# Affirm

Статическое приложение для аффирмаций. Публикуется через GitHub Pages, сервер и сборка не нужны.

## Разработка

```sh
npm ci
npm test
python -m http.server 8765
```

Откройте `http://localhost:8765/`. Зависимости npm нужны только для тестов.

- `assets/catalog.js` — общий каталог для ленты и настроек. ID `u1`, `u2` и т. д. постоянны: не перенумеровывать при сортировке или удалении. Для новых записей использовать новые ID.
- `assets/state.js` — каталог пользователя, уникальные просмотры, круги, XP и миграция.
- `assets/store.js` — последовательные транзакции IndexedDB и уведомления вкладок.
- `assets/app.js`, `assets/settings.js` — интерфейсы ленты и настроек.
- `tests/` — регрессионные сценарии; GitHub Actions запускает их на каждом push и PR.

Старые `.github/*.py` и соответствующие workflow — исторические одноразовые патчи старого HTML. Для разработки текущей версии их повторно не запускать.

## Хранение и переход с предыдущей версии

При первой записи версия 3 переносит из localStorage собственные тексты, правки, удаления, избранное, настройки, XP, достижения, серии, дневные счётчики и время в IndexedDB (`affirm-v3`). Старые ключи не удаляются. IndexedDB гарантирует последовательное изменение общего состояния между вкладками; сообщения BroadcastChannel и storage обновляют интерфейс. Возврат через back-forward cache перечитывает актуальные данные.

Старая очередь хранила подгрузку, а не просмотр. Поэтому незавершённый круг и непроверяемый частичный прогресс уникальных карт дня начинаются заново. Уже начисленные XP и уже выполненная дневная цель сохраняются, повторная награда за тот же день не выдаётся.

Подгрузка не меняет прогресс. Карта засчитывается, когда занимает хотя бы 65% области просмотра в активной вкладке. Повторный показ той же карты того же круга в тот же день не добавляет XP. Круг завершается после просмотра всех его уникальных карт. Цель дня — все уникальные карты активного каталога за текущую локальную дату. Новый день допускает новое начисление за просмотр. Изменение состава каталога начинает новый круг; изменение текста при прежнем ID сохраняет круг.

Браузер без доступа к IndexedDB продолжает работать в памяти и показывает постоянное предупреждение. Изменения в таком режиме исчезнут при переходе на другую страницу или закрытии; их можно скачать на странице настроек. Ошибки записи в доступную базу отображаются пользователю и не подменяются сообщением об успешном сохранении.

В настройках можно скачать JSON-копию и восстановить её, включая пользовательские тексты, избранное, статистику и очередь. Восстановление заменяет текущие данные после подтверждения. Удаление текстов мягкое, с отменой и восстановлением. Старые дубли видны в управлении, а добавление новых дубликатов отклоняется. В ленте дубли показаны один раз.

## Проверки

`npm test` проверяет просмотр/перезагрузку/завершение круга, одновременные записи вкладок, миграцию, резервные копии, смену дня, пустой каталог, дубли, редактирование, back-forward cache, клавиатуру и безопасный вывод HTML. UI-тесты используют jsdom и fake-indexeddb; это не заменяет проверку Safari на настоящем iPhone.


На главном экране остаются время за сегодня и прогресс дневной цели. Нажатие на них открывает «Мой прогресс» с XP, уровнем, серией, кругами и достижениями. Шапка одна на всю ленту; внеэкранные карточки исключены из фокуса.

Колесо мыши и трекпад перелистывают по одной карте за жест с учётом инерции. Длинный текст прокручивается внутри карточки, клавиатура сохраняет эту возможность. Пропущенные при быстром скачке карты возвращаются в конец очереди; в DOM остаются не более 60 карточек. Тесты проверяют эти случаи и доступность окна прогресса.

Для ручной проверки откройте `tests/viewport.html`: там можно переключить реальные размеры окна iframe 320×568, 375×812, 430×932 и 667×375. Проверяйте короткий и 500-символьный текст, избранное, окно прогресса и отсутствие перекрытий. Данные этой страницы общие с приложением в том же браузере; размеры iframe не эмулируют iOS.
